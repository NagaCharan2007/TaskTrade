# TaskTrade

TaskTrade is a campus skill, help, and collaboration platform built for college students.

Students can post tasks or ask for help, apply to tasks posted by others, collaborate on projects, and build a reputation through completed work and reviews.

## 🚀 Features

- 🔐 User Registration and Login
- 🔑 JWT-based Authentication
- 👤 Student Profiles
- 🛠️ Skills Management
- 📋 Create and Manage Tasks
- 🤝 Apply for Tasks
- ✅ Accept Helpers
- 🔄 Track Task Progress
- ⭐ Reviews and Ratings
- 📊 Reputation through Completed Work
- 📧 Contact Requester/Helper
- 🔎 Browse and Search Tasks
- 🌓 Dark and Light Mode
- 📱 Responsive UI

## 🔄 Main Workflow

```text
Student registers
      ↓
Creates a task
      ↓
Other students apply
      ↓
Task owner accepts a helper
      ↓
Task goes In Progress
      ↓
Task is completed
      ↓
Requester reviews the helper
      ↓
Helper builds reputation
